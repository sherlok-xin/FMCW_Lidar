# GitHub publication scope

The user requested GitHub synchronization after this descriptive audit was completed. This publication includes the root audit report, the three append-only project journal/status updates, and this directory's report, 18 CSV tables, six Python scripts, diagnostic PDF/PNG figures, protocols, hashes and validation records.

The original [README](README.md) and [final_manifest.json](final_manifest.json) are preserved byte-for-byte. Their `no_commit_or_push` / “not committed or pushed” statements record the audit-completion snapshot, before the subsequent user instruction to publish. They are not a statement about the later GitHub synchronization. Git history records the publication commit.

The 30 local scene cell-history/persistent-snapshot NPZs are excluded under the existing `*.npz` ignore rule. Their SHA-256 identities remain in the original manifests. Raw bags, PCDs, original raw/fine caches, ROS conversions/recordings/runtime files, and unrelated literature/data-collection work are excluded from this commit. Existing historical files already tracked in the repository are unaffected.

Published tables and figures can be inspected from GitHub. A clone alone cannot execute the full scene validator or reconstruct all causal maps: the local NPZ artifacts and existing raw/fine input caches are required. No detector, score, threshold, graph, label, GNSS calibration or time offset is changed by publication.
