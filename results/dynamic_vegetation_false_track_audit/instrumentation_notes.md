1. Generic `mean(axis=0)` differs slightly from the historical separate strided-column `mean()` reductions in float32. Exact membership reconstruction now uses the same three column reductions as source, without relaxing equality or fitting a tolerance.
2. Frozen `dbscan_trace.csv` repeats the remaining-cluster summary on loop-line trace events. Repeated identical rows are not extra DBSCAN calls. The audit checks the summary content, not row multiplicity. Original artifacts are preserved.
